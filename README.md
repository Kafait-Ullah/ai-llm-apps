## 🔥 AI LLM Apps

A collection of practical applications built using **LangChain**, **Flask**, and **OpenAI APIs** to demonstrate real-world AI/LLM capabilities. Designed with a modular architecture and beginner-friendly Python codebase, these projects showcase how to integrate cutting-edge language models into real applications.

---

## 🧠 What's Inside?

### 📁 `llm_language_translator`

A real-time language translator powered by OpenAI’s LLMs. Input any sentence and get it translated instantly into your target language using LangChain's abstraction for prompt handling and context management.

* 🌍 Supports multiple languages.
* ⚙️ Built with Flask for easy API deployment.
* 🧠 Uses OpenAI's GPT for high-quality translation.

---

### 📁 `llm_resume_match`

An AI-powered resume screening app. Upload a resume and job description — and get a smart matching score with feedback using GPT.

* 🔍 Extracts relevant info from both resume and job description.
* 📊 Provides match percentage + justification.
* 🤖 Ideal for HR tech prototypes or freelancer automation tools.

---

### 📁 `llm_get_json`

Experimental module to extract structured JSON data from unstructured input using LLMs.

* 💡 Great for extracting data from messy text.
* ⚙️ Can be adapted for form-filling, automation, data pipelines.

---

## 🚀 Tech Stack

| Tool       | Purpose                         |
| ---------- | ------------------------------- |
| Python     | Core language                   |
| Flask      | Lightweight web framework       |
| LangChain  | LLM orchestration & prompt mgmt |
| OpenAI API | Powering language understanding |
| JSON       | Data exchange format            |

## 🛠️ Setup Instructions

```bash
# Clone the repo
git clone https://github.com/Kafait-Ullah/ai-llm-apps.git
cd ai-llm-apps

# (Optional) Create virtual environment
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows

# Install dependencies (requirements.txt should be added)
pip install -r requirements.txt

# Run Flask app (modify this based on which app you're running)
cd llm_language_translator  # or llm_resume_match
python app.py
```
